文段6：HTML5表单高频考点梳理
 
HTML5表单模块是期末高频考点，选择题填空题大量出题，表单用来收集用户输入的数据，核心标签form，搭配各种各样的input输入框，还有label、textarea等配套标签。
 
input标签依靠type属性区分不同输入控件，重要type值：
 text 普通单行文本输入框；
 password 密码框，输入字符显示圆点隐藏；
 radio 单选按钮，圆形，同一组单选，name属性必须设置成相同值，才可以实现互斥选择，只能选一个，这个考点反复出现；
 checkbox 复选框，方形，允许多选；
 submit 提交按钮，提交整个表单；
 reset 重置按钮，清空表单全部填写内容；
 button 普通按钮，本身无功能，需要配合JavaScript；
 date 日期选择，弹出日历；
 number 数字输入框，带上下箭头，可设置min最大值max最小值；
 color 调色板；
 file 文件上传控件；
 email 邮箱输入，浏览器自带邮箱格式简单校验；
 range 滑块拖动条。
 
⚠️两个经典错误：不存在 type="select" 下拉框，下拉框要用单独 <select> 标签；普通按钮type是button，不存在type="bottom"，判断题经常拿这两个错误选项挖坑。
 
 <label> 标签：for属性填写input的id值，点击label文字，就会自动聚焦对应的输入框，提升表单可用性。
 <textarea cols="30" rows="10"> 多行文本输入框，cols控制宽度列数，rows控制行数，适合大段文字输入。
 
虽然美味食光三份示例网页没有写完整表单，但是表单属于课程核心，考试占比很高，要分清各个控件外观、功能，记住radio依靠同名name互斥，label for和id绑定关系，避开type常见错误。
